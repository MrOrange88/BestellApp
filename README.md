# Just Steaks – Food Ordering App

A responsive food ordering web application inspired by modern food delivery platforms.

## Features

- Dynamic menu rendering with JavaScript
- Shopping cart functionality
- Add, remove and update item quantities
- Automatic subtotal, delivery fee and total price calculation
- Responsive design for desktop, tablet and mobile devices
- Mobile fullscreen shopping cart
- Order confirmation modal
- Smooth scrolling navigation
- Sticky shopping cart on desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/just-steaks.git
```

2. Open the project folder

```bash
cd just-steaks
```

3. Start the project

Simply open the `index.html` file in your browser.

## Usage

- Browse the menu categories.
- Add dishes to your shopping cart.
- Adjust quantities using the plus and minus buttons.
- Review the subtotal, delivery fee and total price.
- Place your order.
